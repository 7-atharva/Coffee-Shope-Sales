# ☕ Coffee Shop Sales Dashboard – Microsoft Excel

## 📌 Project Overview
This project presents an interactive Coffee Shop Sales Dashboard built using Microsoft Excel to analyse sales performance, customer footfall, order trends, and product performance across multiple store locations.

## 🎯 Objectives
- Track key sales and customer performance indicators.
- Analyse order patterns by hour and weekday.
- Identify top-selling products and popular product categories.
- Compare sales and footfall across store locations.
- Present insights through an interactive dashboard.

## 🛠️ Tools & Technologies
- **Microsoft Excel**
- Data Cleaning and Transformation
- KPI Calculation and Data Analysis
- Charts and Interactive Filters

## 📊 Key Performance Indicators (KPIs)
- **Total Sales:** $698,812.33
- **Total Footfall:** 149,116
- **Average Bill per Person:** 4.69
- **Average Order per Person:** 1.44

## 📈 Dashboard Features
1. **Quantity Ordered by Hour** – Analyses order quantities throughout the day.
2. **Category-wise Sales Distribution** – Shows the percentage contribution of each product category to sales.
3. **Order Size Distribution** – Displays the distribution of orders by size.
4. **Store Performance** – Compares sales and customer footfall across Astoria, Hell's Kitchen, and Lower Manhattan.
5. **Top 5 Products by Sales** – Highlights the highest-performing products based on sales.
6. **Weekday Order Trends** – Compares order activity across the seven days of the week.
7. **Interactive Filters** – Enables filtering by month and day for focused analysis.

## 🔄 Data Preparation
- Cleaned and transformed the sales data for analysis.
- Prepared data for KPI calculations and visualisations.
- Organised sales information to support comparisons across products, time periods, and store locations.

## 💡 Key Insights
- Coffee contributes the largest share of category sales in the displayed dashboard.
- Hell's Kitchen records the highest sales among the three displayed store locations.
- Barista Espresso is the top product by sales among the five products shown.
- Order quantities vary by hour, with the highest levels occurring during the morning period.
